# WebGL Midterm Project - Magic Library
The magic library has three floor-to-ceiling bookshelves full of books. Candles float near the ceiling. In the middle, there's a desk and a chair. On the desk is a floating book, a magic wand, and a potion. Every time you visit the library anew the books and candles have moved postions.
## Controls
	P - pause animation

	D - drink/refill the potion

	O - turn the lights on/off
